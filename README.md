# TaskTracker

## Descrição
O TaskTracker é um programa desenvolvido em Python para ajudar na organização e no acompanhamento de tarefas. Ele permite cadastrar tarefas, definir prioridades e visualizar suas informações e seus status.

## Tecnologias utilizadas
- Python 3
- Git
- GitHub

## Como executar
1. Instale o Python 3 no computador.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

```bash
python src/main.py
```

## Funcionalidades
- Cadastrar tarefas.
- Informar título, descrição, prioridade e data limite.
- Definir automaticamente o status como Pendente.
- Visualizar as tarefas cadastradas.
- Validar o preenchimento do título e a prioridade escolhida.
